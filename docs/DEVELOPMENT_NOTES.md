# 开发过程记录

以下根据原课程《项目实现过程.docx》整理，是当时开发过程的记录，不是本次重新运行项目后的检查结论。

## 个人完成的工作

课程项目为个人作业，代码开发使用AI辅助。模型、环境和音频包含外部素材。

1. 寻找场景、赵州桥和NPC素材；使用Cinema 4D将桥模型从C4D转换为FBX，再导入Unity。
2. 配置第一人称视角与移动，以及NPC对话、构件收集、知识问答和桥体修复的任务流程。
3. 调整对话框与知识弹窗的大小、透明度和排版，衔接任务与结局。
4. 配置收集提示光柱、修复粒子效果、背景音乐和音效。
5. 运行检查并排查问题；修复阶段原先计划拖动锤子，后来因实现问题改为点击高亮部位。
